# API Contract

/api/auth/login - POST - User login
/api/auth/signup - POST - User signup
/api/auth/forgot-password - POST - Send reset link
/api/auth/verify-otp - POST - Verify OTP code

/api/jobs - GET - List all jobs
/api/jobs - POST - Create new job
/api/jobs/:id - PUT - Update job
/api/jobs/:id - DELETE - Delete job

/api/candidates - GET - List all candidates

/api/recruiters - GET - List all recruiters
/api/recruiters - POST - Add new recruiter

/api/interviews - GET - List all interviews
/api/interviews - POST - Schedule new interview
